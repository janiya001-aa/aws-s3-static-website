# AWS S3 Static Website

A static website hosted using Amazon S3.

## Project Overview

This project demonstrates how to deploy and host a static website using Amazon Web Services (AWS) S3.

## Technologies Used

- Amazon S3
- HTML
- CSS
- Git
- GitHub

## AWS S3 Configuration

- Created an S3 bucket
- Uploaded the website files
- Configured static website hosting
- Set `index.html` as the index document
- Configured permissions for website access
- Tested the live website
